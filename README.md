# Corp Civ Idle (browser MVP)

Phase 1 prototype for the design in `Corp Civ Idle Game - Game Design Doc.docx`.

## Run locally

Requires [Node.js](https://nodejs.org/) 20+.

```bash
cd corp-civ-idle
npm install
npm run dev
```

## What's implemented

- Top resource bar, left sidebar, main view (GDD layout)
- Idle tick production for R1 resources (cash, power, influence drip)
- Structures and research trees, contractor hiring, project bidding
- Hex world map placeholder with government center + HQ
- Office / secretary view placeholder
- Auto-save to `localStorage`
- Changed repo to public
